# zaiki_app

## Project

- Flutter application using Dart 3.11 or newer.
- Firebase is used for Firestore, Storage, Messaging, and Cloud Functions.
- The main application code is under `lib/`.
- Cloud Functions are under `functions/` and use Node.js.
- Estimate data is stored in `assets/data/` and is generated by scripts in `scripts/`.

## Development Rules

- Preserve existing Flutter and Firebase architecture unless the task requires a change.
- Keep changes focused and avoid modifying generated platform files unless necessary.
- Do not expose Firebase credentials, API keys, user data, or local secrets.
- Before changing behavior, inspect nearby callers and existing patterns.
- Add or update focused tests for non-trivial behavior changes.

## Validation

Run the narrowest relevant checks first:

```bash
flutter analyze
flutter test
```

For Cloud Functions changes:

```bash
cd functions
npm install
npm test
```

When `npm test` is not configured, at minimum verify the JavaScript syntax and dependencies before deployment.

## Firebase

- Firestore rules: `firestore.rules`
- Storage rules: `storage.rules`
- Deploy rules with `firebase deploy --only firestore:rules,storage`
- Deploy functions with `firebase deploy --only functions`
- Do not deploy Firebase resources without explicit user approval.
